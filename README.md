# Экран на ТВ

iOS-приложение показывает экран iPhone в браузере телевизора по Wi-Fi. Одновременно можно подключить два телефона: их экраны встанут рядом.

## Как это устроено

- **Приложение** (`App/`) показывает адрес для телевизора, кнопку запуска вещания и признак того, что вещание идёт.
- **Расширение трансляции** (`Broadcast/`) получает кадры экрана через ReplayKit, уменьшает их до 1280 px по длинной стороне и раздаёт по сети:
  - WebSocket на порту 8081 — видео H.264 до 30 кадров в секунду, около 4 Мбит/с. Сжимает аппаратный кодировщик телефона;
  - HTTP на порту 8080: `/` — страница для телевизора (`Broadcast/tv.html`), `/stream` — запасной поток MJPEG, `/status` — адреса других телефонов, найденных через Bonjour.
- **Страница для телевизора** показывает H.264 через Media Source Extensions с помощью [jmuxer](https://github.com/samirkumardas/jmuxer) (MIT, лежит в `Broadcast/jmuxer.min.js`). Если браузер не умеет H.264 или видео не пошло за 8 секунд, страница переключается на MJPEG. На подписи телефона видно, какой режим выбран и сколько кадров в секунду показывается.
- Страница опрашивает `/status`. Когда появляется второй телефон, она сама подключает его поток и ставит экраны рядом. Если телефон перестаёт отвечать, его экран исчезает через 6 секунд. Если телефон возвращается, экран появляется снова.

Звук не передаётся.

## Сборка

Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen). Файл `.xcodeproj` в репозиторий не кладётся.

Собирает GitHub Actions (`.github/workflows/build.yml`) на облачной macOS при каждом push. Готовый файл `ScreenShare.ipa` лежит в артефакте `ScreenShare-ipa` на странице запуска (вкладка Actions). IPA собрана без подписи.

Сборка на своём Mac:

```bash
brew install xcodegen
xcodegen generate
open ScreenShare.xcodeproj
```

## Установка на iPhone с Windows

1. Установи iTunes и iCloud с сайта Apple, не из Microsoft Store: Sideloadly нужны их драйверы.
2. Установи [Sideloadly](https://sideloadly.io).
3. Подключи iPhone кабелем, перетащи `ScreenShare.ipa` в Sideloadly, введи Apple ID и нажми Start.
4. На iPhone открой Настройки → Основные → VPN и управление устройством и доверяй своему Apple ID.
5. На iOS 16 и новее включи Настройки → Конфиденциальность и безопасность → Режим разработчика. Телефон перезагрузится.
6. При первом запуске разреши доступ к локальной сети. Без этого телефоны не найдут друг друга.

С бесплатным Apple ID подпись действует 7 дней. После этого переустанови приложение через Sideloadly.

## Использование

1. Подключи телефон и телевизор к одной сети Wi-Fi.
2. Открой «Экран на ТВ» и нажми кнопку вещания → «Начать вещание».
3. Открой в браузере телевизора адрес из приложения, например `http://192.168.1.23:8080`.
4. На втором телефоне просто начни вещание. Его экран появится на телевизоре сам.

Если второй телефон не появляется, значит роутер не пропускает Bonjour. Добавь адрес второго телефона после `#`: `http://192.168.1.23:8080/#192.168.1.24:8080`.

Ещё одна причина: в гостевых сетях роутер часто изолирует клиентов друг от друга, и тогда телевизор не видит телефоны совсем.
